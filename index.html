👨‍💻 About Me

I am a Microsoft Cybersecurity Architect specializing in Zero Trust security architectures for enterprise and regulated environments. My work focuses on identity protection, conditional access, device trust, and modern workplace security across Microsoft cloud platforms.

I leverage industry-leading security frameworks including MITRE ATT&CK, NIST Cybersecurity Framework (CSF), ISO 27001/27002, and CIS Controls to design threat-informed defense strategies and implement comprehensive security controls using Microsoft Defender XDR and Microsoft Sentinel for enterprise-scale protection.
